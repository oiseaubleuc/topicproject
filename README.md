## Features

- User registration and login with Django's built-in authentication
- Full CRUD back office generated by the Django admin
- MVT architecture split into apps

## What this project compares

| Topic | Django | Laravel |
|---|---|---|
| Architecture | MVT (models, views, templates) | MVC (models, controllers, views) |
| Admin | Generated automatically from models | Built by hand |
| Auth | `django.contrib.auth` | Breeze / Fortify |
| CLI | `manage.py` | `artisan` |

**Key takeaways:** the built-in admin and the app structure make Django fast to prototype with. Email configuration was the main difficulty in both frameworks.

## Getting started

```bash
git clone https://github.com/oiseaubleuc/topicproject.git
cd topicproject
python3 -m venv venv
source venv/bin/activate
pip install django
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver        # http://127.0.0.1:8000
```
